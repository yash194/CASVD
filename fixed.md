  CRITICAL ISSUE #1: Alpha is Diverging — Target Entropy is Unreachable
                                                                                                                                                                                                                                                                                                                              
  This is the single biggest problem killing your algorithm.
                                                                                                                                                                                                                                                                                                                              
  # sac_learner.py:86
  self.target_entropy = -th.log(th.tensor(1.0 / self.n_actions)).item() * 0.98                                                                                                                                                                                                                                                
                                                                                                                                                                                                                                                                                                                              
  For protoss_5_vs_5: n_actions = 6 + max(5,5) = 11, so target_entropy = log(11) * 0.98 ≈ 2.35.                                                                                                                                                                                                                               
                                                                                                                                                                                                                                                                                                                              
  But this target is unreachable. Here's why:                                                                                                                                                                                                                                                                                 
                  
  1. Action masking kills achievable entropy. Dead agents can ONLY no-op (entropy = 0). Living agents can only attack visible enemies + move. In practice, 4-6 actions are available, not 11. Maximum achievable entropy ≈ log(5) ≈ 1.6.                                                                                      
  2. Optimal play requires coordination, not randomness. A good policy SHOULD be more deterministic — focus fire on one enemy, kite melee units, etc. Target entropy of 2.35 forces near-uniform randomness.
  3. The alpha update loop is a death spiral:                                                                                                                                                                                                                                                                                 
  entropy (1.17) < target (2.35) → alpha increases → policy pushed toward randomness                                                                                                                                                                                                                                          
  → random policy can't coordinate → agents die → more dead agents (entropy=0)                                                                                                                                                                                                                                                
  → average entropy drops further → alpha increases MORE                                                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                                                                                                              
  3. Current alpha = 2.89 means the actor loss penalizes being decisive by ~2.89 per nat of "missing" entropy. This actively prevents the policy from learning to focus fire or coordinate.

  CRITICAL ISSUE #2: Q-Value Overestimation + Critic Instability
                                                                
  Q-values (~28) are ~5x the actual returns (~5.5). The targets (~28) confirm the bootstrapping is propagating this error.
                                                                                                                                                                                                                                                                                                                              
  Root causes:
                                                                                                                                                                                                                                                                                                                              
  A. Alpha inflates soft Q-values. The target includes alpha * H(pi):                                                                                                                                                                                                                                                         
  target_v = (target_probs * (target_q_min - self.alpha * target_log_probs)).sum(dim=-1)
  With alpha=2.89, each step adds ~2.89 * entropy to the value, inflating Q-values above actual returns. As alpha rises, Q-values rise, but they become disconnected from reward signal.                                                                                                                                      
                                                                                                                                                                                                                                                                                                                              
  B. SACTypeCritic's additive structure amplifies overestimation. For 3 unit types:                                                                                                                                                                                                                                           
  # sac_type_critic.py:137                                                                                                                                                                                                                                                                                                    
  q1_out[:, :, agent_idx, :] = q1_coord + q1_type                                                                                                                                                                                                                                                                             
  The GlobalCoordinator adds a bonus on top of the type-specific Q. Both can independently overestimate, and the sum amplifies the error. The twin-Q min trick (min(Q1, Q2)) helps for each network pair, but the additive structure creates a bias that min doesn't correct.                                                 
                                                                                                                                                                                                                                                                                                                              
  C. Critic gradient norms of 125-523 with clip at 10. This means 90-98% of gradient information is destroyed every update. The critic is barely learning. The direction is preserved but magnitude is crushed, making updates ineffective for correcting large TD errors.

  CRITICAL ISSUE #3: No Parameter Sharing Between Agents                                                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                                                                                                              
  # gat_ns_agent.py:148
  self.agents = nn.ModuleList([                                                                                                                                                                                                                                                                                               
      IndividualAgentNet(self.hidden_dim, self.n_actions, ...)
      for _ in range(self.n_agents)                                                                                                                                                                                                                                                                                           
  ])              
                                                                                                                                                                                                                                                                                                                              
  5 separate RNN + policy heads, zero weight sharing. Each agent's policy head sees only its own data — 1/5 the effective sample size.                                                                                                                                                                                        
   
  QMIX uses n_rnn with full parameter sharing — every agent's experience trains the same network. This is why QMIX can learn with much less data.                                                                                                                                                                             
                  
  In a 5v5 Protoss scenario with procedural generation (random team compositions), the agents have different unit types each episode. A shared policy conditioned on unit type would be far more sample-efficient than 5 separate policies where agent_0 sometimes is a Stalker, sometimes a Zealot.

  MAJOR ISSUE #4: LGDD Pre-training is Counterproductive
                                                                                                                                                                                                                                                                                                                              
  During Phase 1 (0-100k steps):
  - Random actions are taken (lgdd_random_warmup: True)                                                                                                                                                                                                                                                                       
  - Encoder is trained via LGDD to predict next-state latents from random actions                                                                                                                                                                                                                                             
  - RL gradients are blocked from encoder (detach_encoder=True)                  
                                                                                                                                                                                                                                                                                                                              
  Problems:                                                                                                                                                                                                                                                                                                                   
  1. Random actions produce chaotic dynamics. Predicting z_{t+1} from random a_t teaches the encoder about what happens when agents act randomly — not what happens under coordinated play.                                                                                                                                   
  2. 100k steps of zero learning. That's ~5% of your 2.05M budget spent learning useless representations.                                                                                                                                                                                                                     
  3. After Phase 1, the encoder has to unlearn. When RL kicks in at 100k, the representations are tuned for random dynamics, not Q-value estimation. The encoder must fight against LGDD representations.
                                                                                                                                                                                                                                                                                                                              
  During Phase 2 (100k+ steps):                                                                                                                                                                                                                                                                                               
  - LGDD continues with weight 0.1                                                                                                                                                                                                                                                                                            
  - lgdd_grad_norm: 0.007-0.01 — essentially zero                                                                                                                                                                                                                                                                             
  - LGDD is doing nothing but adding compute cost

  MAJOR ISSUE #5: SAC Fundamentally Conflicts with Cooperative MARL                                                                                                                                                                                                                                                           
                                                                                                                                                                                                                                                                                                                              
  SAC's core principle is maximum entropy — be as random as possible while still maximizing reward. This works great in single-agent continuous control where:
  - Exploration is the bottleneck                                                                                                                                                                                                                                                                                             
  - The agent only needs to coordinate with itself                                                                                                                                                                                                                                                                            
  - Continuous action spaces benefit from stochastic policies                                                                                                                                                                                                                                                                 
                                                                                                                                                                                                                                                                                                                              
  In cooperative MARL (5v5 StarCraft):                                                                                                                                                                                                                                                                                        
  - Coordination is the bottleneck, not exploration                                                                                                                                                                                                                                                                           
  - 5 agents all being random simultaneously → probability of discovering good joint actions is exponentially small (~(1/n_actions)^n_agents)                                                                                                                                                                                 
  - Focus fire (all agents attacking one enemy) has probability ~(1/5)^5 = 0.00032 under random play                                                                                                                                                                                                                          
  - Epsilon-greedy with parameter sharing (QMIX) discovers coordination much faster because the shared network learns from ALL agents' experiences

  MAJOR ISSUE #6: Critic Architecture is Mismatched                                                                                                                                                                                                                                                                           
                                                                                                                                                                                                                                                                                                                              
  The critic takes state + obs + agent_id as input:
  # sac_type_critic.py:147-158                                                                                                                                                                                                                                                                                                
  pieces = [                  
      batch["state"][:, ts].unsqueeze(2).expand(-1, -1, self.n_agents, -1),  # global state                                                                                                                                                                                                                                   
      batch["obs"][:, ts],  # per-agent obs                                                
      agent_id_onehot  # identity                                                                                                                                                                                                                                                                                             
  ]                                                                                                                                                                                                                                                                                                                           
                                                                                                                                                                                                                                                                                                                              
  But the critic has no recurrence and no attention. It's a simple 2-layer MLP. The actor is a sophisticated GAT with attention over entities and team communication. But the critic — the thing that provides learning signal — is a dumb MLP. The actor is smarter than the thing teaching it.                              
                                                                                                                                                                                                                                                                                                                              
  Also, with 3 unit types, you have 3 TwinQNetworks (6 Q-networks) + 2 GlobalCoordinators = 8 networks for the critic. This is massively over-parameterized for 5 agents, and all 8 networks share the same MLP architecture that can't even do attention over entities.

  MODERATE ISSUES 
                 
  #7: Reward standardization hides signal. With 0% wins, the reward distribution is very narrow (small damage values). Standardization compresses this further. When the agent finally does something good, the reward looks similar to other steps.
                                                                                                                                                                                                                                                                                                                              
  #8: Batch size 32 is too small for SAC. QMIX uses 128. With stochastic policies and per-agent networks, you need larger batches to reduce gradient variance.                                                                                                                                                                
                                                                                                                                                                                                                                                                                                                              
  #9: gain: 0.01 makes critic learn slowly. All weights initialized near zero means Q-values start near zero and take many updates to reach meaningful values.                                                                                                                                                                
                  
  #10: CL is premature. Continual learning prevents forgetting, but there's nothing worth remembering. The cl_distill_loss ≈ 0.0007 confirms teacher ≈ student (both equally bad). It's just adding overhead.

  QMIX's value decomposition guarantees that improving each agent's local Q-value improves the joint Q-value. GAT-SAC has no such guarantee — each agent optimizes independently and coordination must emerge from the critic's guidance, which is itself struggling.

  Ranked Fix Priority
                     
  Must Fix (These alone block any progress):
                                                                                                                                                                                                                                                                                                                              
  1. Fix target entropy — Set to 0.3-0.5 * log(n_actions) or better yet, compute it from average available actions. Also consider clamping alpha to a maximum value (e.g., 1.0).                                                                                                                                              
  2. Add parameter sharing — Replace nn.ModuleList of 5 agents with a single shared agent conditioned on agent_id (which is already in the input).                                                                                                                                                                            
  3. Increase critic grad_norm_clip — From 10 to at least 40-50 for the critic, or use a separate clip value.                                                                                                                                                                                                                 
                                                                                                                                                                                                                                                                                                                              
  Should Fix (Major impact):                                                                                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                                                                              
  4. Remove or drastically shorten LGDD Phase 1 — Either disable random warmup entirely, or reduce to 10k steps. Let the encoder learn from RL signal from the start.                                                                                                                                                         
  5. Increase batch size — To at least 64, ideally 128 to match QMIX.
  6. Make the critic more expressive — Give it attention (or at minimum, larger hidden dims). The entity structure that GAT exploits in the actor should also be in the critic.                                                                                                                                               
                  
  Consider (Moderate impact):                                                                                                                                                                                                                                                                                                 
                  
  7. Disable CL until the base algorithm works.
  8. Increase hidden_dim for critic or use separate (larger) critic hidden.
  9. Use shared-weight agents with unit-type conditioning instead of per-type critics.
  10. Consider value decomposition — The GAT encoder is powerful, but without value decomposition, there's no coordination mechanism. You could use GAT as the agent in a QMIX-like framework.

  The Fundamental Insight
                         
  Your GAT architecture is genuinely powerful for multi-agent settings — attention over entities and team communication is the right inductive bias. But SAC's entropy maximization is the wrong training objective for cooperative MARL. The complexity of LGDD, CL, type-critics are additions that try to compensate for
  this fundamental mismatch.                                                                                                                                                                                                                                                                                                  
   
  The path forward is either:                                                                                                                                                                                                                                                                                                 
  - A: Keep the GAT encoder but pair it with a value decomposition method (QMIX-style mixer) instead of SAC
  - B: Fix SAC to work for MARL (drastically lower entropy target, add parameter sharing, strengthen the critic) — this can work but requires getting every detail right  






  Honest answer: No, not automatically.                                                                                                                                                                                                                                                                                       
                                                                                                                                                                                                                                                                                                                              
  Fixing the bugs (alpha divergence, no parameter sharing, critic instability) will take you from broken to functional. You'll go from 0% win rate to actually learning something. That's a huge step.                                                                                                                        
                                                                                                                                                                                                                                                                                                                              
  But "outperforming QMIX and becoming SOTA" requires more than bug fixes. Here's the reality:                                                                                                                                                                                                                                
                                                                                                                                                                                                                                                                                                                              
  After fixes, you'll likely match QMIX — because once parameter sharing and proper entropy tuning are in place, you've essentially rebuilt a working MARL algorithm. The GAT encoder gives you better entity reasoning than QMIX's plain RNN, which helps on heterogeneous maps like protoss_5_vs_5.                         
                  
  To actually beat QMIX convincingly, you need a structural advantage, not just a fancier encoder. The things that could give you that edge:                                                                                                                                                                                  
                  
  1. Value decomposition + GAT — Your GAT encoder is genuinely powerful. But SAC's independent per-agent optimization has no coordination mechanism. If you feed GAT representations into a QMIX-style mixer, you get the best of both worlds: structured entity reasoning + guaranteed coordination improvement. This alone  
  could beat QMIX.
  2. The LGDD idea has merit, but not with random actions — Pre-training representations with a world model is a good idea (Dreamer, IRIS prove this). But you need on-policy or at least semi-useful data, not random chaos. Consider running LGDD alongside RL from step 0 as an auxiliary loss, not a separate phase.      
  3. CL only matters if you're doing curriculum or distribution shift — For fixed protoss_5_vs_5, it's dead weight. It becomes valuable if you train across multiple maps or do curriculum learning.                                                                                                                          
                                                                                                                                                                                                                                                                                                                              
  Bottom line: The GAT architecture is your real innovation and it has genuine potential. But wrapping it in SAC for cooperative MARL is fighting uphill. GAT + value decomposition (QMIX/QPLEX-style) is the most natural path to SOTA on SMACv2. The fixes I listed will make your current code work, but the architectural 
  pairing determines whether it excels.
